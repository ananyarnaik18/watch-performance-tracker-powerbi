# ⌚ Watch Performance Tracker Dashboard | Power BI

## 📌 Project Overview

The **Watch Performance Tracker Dashboard** is an interactive Power BI dashboard designed to analyze sales performance, budget tracking, customer segments, and category growth using business intelligence techniques.

The dashboard provides decision-makers with a quick overview of key business metrics through visually appealing KPI cards, donut charts, bar charts, and trend analysis.

## Features

- 📈 Year-to-Date (YTD) Sales Analysis
- 💰 Budget Performance Tracking
- 📊 Sales by Product Category
- 👥 Sales by Customer Segment
- 📅 Monthly Order Trend Analysis
- 📌 Growth Comparison (2022 vs 2023)
- 🎨 Modern Dark Theme Dashboard Design
- ⚡ Interactive Power BI Visuals
